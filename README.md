# TP-1-mathematique-
 Ce programme en C propose un menu permettant soit de résoudre l’équation a·x + b·y = c grâce au PGCD, au PPCM et à l’algorithme d’Euclide étendu, soit d’afficher tous les nombres premiers inférieurs à un entier n. Il organise ces opérations dans des fonctions séparées pour plus de clarté.
